# Politica de seguridad de CoreVigil

Gracias por ayudar a mantener CoreVigil seguro.

## Versiones con soporte

CoreVigil se mantiene actualmente como un proyecto personal en modo mantenimiento. La rama principal vigente es la referencia para correcciones de seguridad.

No se promete soporte indefinido para versiones historicas, forks de terceros ni binarios modificados fuera de este repositorio.

## Reportar una vulnerabilidad

No publiques detalles explotables de una vulnerabilidad en issues, discusiones o pull requests publicos.

Si GitHub muestra la opcion **Report a vulnerability** o permite crear un reporte privado de vulnerabilidad para este repositorio, utiliza ese canal.

Si el reporte privado no esta disponible, solicita un canal privado de contacto sin publicar detalles tecnicos de la vulnerabilidad. No incluyas pruebas de concepto, credenciales, datos personales ni instrucciones de explotacion en un issue publico.

## Informacion util para el reporte

Cuando exista un canal privado, incluye en lo posible:

- version, commit o rama afectada;
- componente o archivo relacionado;
- condiciones necesarias para reproducir el problema;
- impacto observado;
- pasos de reproduccion suficientes para validar el problema;
- una propuesta de correccion, si la tienes.

Evita incluir datos personales, secretos o informacion de terceros que no sea necesaria para analizar el reporte.

## Alcance

Son relevantes, entre otros, problemas que afecten la seguridad del codigo de CoreVigil, su persistencia local, la interaccion con Windows, el manejo de archivos o cualquier comportamiento que pueda exponer informacion o ejecutar acciones no previstas.

Los problemas exclusivos de forks o modificaciones de terceros deben reportarse primero a sus respectivos mantenedores, salvo que tambien afecten al codigo vigente de CoreVigil.

## Divulgacion responsable

Da tiempo razonable para investigar y corregir una vulnerabilidad antes de divulgar detalles publicamente. Una vez exista una correccion y sea apropiado documentarla, el proyecto podra registrar el cambio correspondiente en su historial.

## Sin programa de recompensas

CoreVigil no mantiene actualmente un programa de recompensas por vulnerabilidades. Los reportes responsables son bienvenidos y se agradece la colaboracion de la comunidad.
